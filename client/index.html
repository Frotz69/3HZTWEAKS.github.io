The launcher

Native, because a launcher should open instantly.

It started life as an Electron page. It is not one any more: the window is Win32, the surfaces are DirectX 11, and the UI is drawn with Dear ImGui — the same stack as 3HZ Tweaks.

Same design language

The interface

One window instead of a tab per category.

Ported from the client's own WindowClickGui component — category rail, module list with state dots, and the selected module's settings on the right. It is live: flip a switch, search, drag a slider.

Recreated at the component's real geometry and palette. State lives in this page only — the in-game window talks to the client instead.

How it works

Modules

The module set comes with the client.

3HZ Client inherits the module catalogue of the base it is built on and reskins it. Categories you can expect in the ClickGUI:

Combat

Aim, click and timing modules, each with its own settings in the side pane.

Movement

Sprint, jump and travel behaviour.

Render

HUD elements, ESP-style overlays and visual toggles.

World

Interaction with blocks and the environment.

Player

Inventory and self-management helpers.

Misc

Everything that does not fit the other five, including the client's own utilities.

The base project's module list is large; this page names categories, not a count it cannot verify.

FAQ

Straight answers.

Is this a from-scratch client?

No — it is the LiquidBounce NextGen codebase, renamed and rebranded, with its own theme and launcher. Saying otherwise would be dishonest, and the project is better for being clear about its base.

Why does a Minecraft client need a C++ launcher?

Because the first version was Electron and it felt like it. The rebuild uses Win32 + DirectX 11 + Dear ImGui, which opens instantly and matches 3HZ Tweaks. It also means the launcher can genuinely run Gradle and start the game.

Will the CEF interface still work after the rename?

Yes. The bundled CEF module depends on the liquidbounce mod id, so the renamed mod declares provides: ["liquidbounce"]. Without that, Fabric refuses to load the client at all — the exact crash this fixes.

Where do I download it?

There is no hosted installer yet. It is a source build: clone the client, point the launcher at the Gradle project, and use “Build & install”. Hosting a compiled Minecraft mod is a different problem from hosting a Windows installer, and this page will not pretend it is solved.

Is singleplayer/offline covered?

3HZ Client is a client for Minecraft, not a replacement for it — you still need a legitimate Minecraft installation. Nothing here bypasses authentication or distributes game assets.
