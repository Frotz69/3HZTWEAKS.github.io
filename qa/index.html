FAQ

Before you install.

Every tweak writes the previous registry or service state to a backup file before applying. “Revert all” reads those backups and restores the machine. Nothing is deleted, and no tweak runs until you ask for it.

No, and it does not have a model to download either. 3HZ AI ships inside the app and runs on your CPU: it reads your real hardware profile locally and answers from the tuning knowledge base baked into the binary. There is no key field, no endpoint and no per-question limit - it is the Ultra tier that unlocks the page, not an internet connection.

Five everyday ones work on any plan, Free included: Wi-Fi disconnect, DNS flush, clearing the shader cache, emptying the recycle bin and restarting Explorer. The other seventeen are Ultra - the Wi-Fi scan and saved-password reveal, the route test and DHCP renew, the network-stack reset, every debloat tool including the package picker that lists what Windows shipped, the temp-file cleanup, the SSD TRIM, the drive health report and the XMP/EXPO memory check that restarts into the firmware. They unlock the moment an Ultra key is pasted into Account - no restart, no download, and Pro does not include them.

Steam, Epic, EA and Ubisoft installations are scanned automatically, including extra Steam library folders on other drives. Anything else can be added manually.

Checkout runs on Stripe: pay by card, and a licence key for that plan is emailed to you and shown on the thank-you page. Paste it into Account → Have a key? in the app and the plan stays unlocked offline. Pro and Ultra are separate keys, so buying Ultra later does not cancel Pro - the app simply shows the better plan. Billing is monthly; cancelling from the Stripe receipt drops you back to Free and never reverts a tweak you applied.

These are Windows and driver-level settings, not game modification. They do not touch game files or memory. Some competitions still have their own rules, so check them if you play on a stage.

Yes, and it is not a re-skin: Macs have no registry, so the macOS build has its own backend behind the same window - defaults for preferences, pmset for power, sysctl and vm_stat for the numbers, diskutil for drives. It carries 20 Mac-only tweaks (hide the Dock, scale minimise, full path in the Finder title, fast key repeat, less motion, reduce transparency, dark mode, no screenshot shadows) and a Mac disk cleaner for caches, logs, Xcode derived data and package caches.

Apple apps can only be compiled on a Mac, so there is no installer to hand out: the download is the source with build-macos.command in it. Unzip, double-click that file, and it checks for the Xcode command line tools and CMake (offering to install CMake with Homebrew), builds the app and opens it. It is unsigned, so the first launch needs right-click → Open. Free, same as the Windows build.

3hzTweaks-Setup.zip (3 MB) holds the installer plus its app folder; run 3hzTweaksSetup.exe from inside the unzipped folder and it copies the app, its two fonts and its uninstaller to the folder you choose. 3hzTweaks-Portable.zip (2 MB) is the app itself: 3hzTweaks.exe with Inter.ttf and fa-solid-900.ttf next to it, which must stay together - unzip the folder anywhere and run the .exe.

Check the download with certutil -hashfile 3hzTweaks-Setup.zip SHA256 in the folder you saved it to. It should print:

8105cb1e5edf1e8f8438a3d91fdaa9879c3f4a1bcce955536eec6367434af669 for the installer zip, and
7ad79a13c3b590eda3fd448f82e7de4d84564e1ab6ab0b38120d17caae7968ec for the portable zip.

3hzTweaks-macOS-source.zip (2 MB) is the Mac build's source in 3hzTweaks-macOS/, with build-macos.command beside it. Its sha256 is
1ee9ddfc137a0974faa5a51471e2f7fce50dd0272b1c23560e6bb8c237998113 - check it on a Mac with shasum -a 256 3hzTweaks-macOS-source.zip.
